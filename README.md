# Netflix Secret Codes

A mobile-first Netflix Secret Codes navigator.

## Features

- 20 main categories displayed in a 4 × 5 grid on desktop
- Click a category to view its subcategories
- Each subcategory links directly to the corresponding Netflix collection
- Back and Home navigation
- Browser history support
- Responsive mobile layout
- No build step or dependencies

## Deploy to GitHub Pages

### Option 1: Upload this repository

1. Create a new GitHub repository.
2. Upload all files from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Save.

GitHub will publish the site at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Local use

Open `index.html` in a web browser.

## Important

Netflix collections and titles vary by country, profile, licensing, and catalogue availability.
